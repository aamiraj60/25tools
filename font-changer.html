FAQ

Frequently asked questions

Is this font changer really free?

Yes — every style, every time, unlimited. There is no account, no watermark, no download and no paywall. The tool is funded by nothing but goodwill and runs entirely in your browser.

Will fancy text actually work on Instagram and TikTok?

Yes. Instagram bios, TikTok captions and comments, Discord names, Roblox display names and YouTube channel names all accept Unicode characters — which is exactly what these fonts are. The text is real text, not an image, so it stays selectable and copyable.

Does it work on iPhone and Android?

Yes. ToolGuest runs in any modern mobile browser — Safari on iOS, Chrome on Android — with no app install. Tap a card to copy, then long-press → Paste inside the target app.

Is my text sent to a server?

Never. 100% of the conversion happens locally through JavaScript string mapping against the Unicode standard. Nothing is uploaded, logged, cached or sold.

Why do some styles show empty boxes on certain devices?

A small number of older devices lack system fonts containing rare Unicode glyphs, so they render as tofu (□). 95%+ of modern phones and browsers display every style here perfectly. If one looks broken, try another.

Can I use these fonts in my username or @handle?

Usually yes for display names, but many platforms restrict special characters in the actual @handle. If a handle is rejected, use the fancy text in the display name or bio field instead.

Are these real fonts I need to install?

No. These are Unicode characters that already exist inside the fonts on every device. That's why they copy and paste perfectly anywhere, with no .ttf file to download.
