      Yes. The analysis runs entirely in your browser using JavaScript — there is no server call at all. If you want proof, open your browser's developer tools, switch to the Network tab, and watch it stay empty while you type.

      Entropy measures how many guesses a password resists, in bits. Every extra bit doubles the work. Under 40 bits falls quickly to an offline attack; 60 bits is reasonable; 80 bits and above is comfortably strong for the foreseeable future.

      We take the entropy, halve it (the average case when guessing), and divide by ten billion guesses per second — a realistic figure for a modern offline GPU rig attacking a fast hash. Online attacks with rate limits are far slower.
